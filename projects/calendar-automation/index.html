Project 05 • Automation

Semester Calendar Automation

An AppleScript workflow that converts spreadsheet schedules into calendar events and distributable ICS files.

Challenge

Teaching schedules arrive as spreadsheets. Manually entering each class, time, room, recurrence, and date into a calendar creates repetitive work and transcription risk.

Design response

The script reads the structured schedule, uses semester-start information to create recurring events, and produces calendars for individual teachers and classes. ICS files are sent by email so recipients can open them in their usual calendar application.

How it works

  1. Receive the official semester spreadsheet.
  2. Prepare it in the expected structured layout.
  3. Run the script and provide the semester dates.
  4. Generate calendars and ICS files.
  5. Email the files for direct import.

Reach and reflection

The workflow removes repeated manual entry for me and has been imported by several colleagues on their phones. It is reusable each semester with limited adjustment. No formal time study has been completed.

Evidence to addAnonymized schedule excerpt, process diagram, calendar screenshot, example ICS event, short code excerpt, and a 30–60 second recording.

Lesson learned

A useful automation needs a stable input, a repeatable transformation, and an output that ordinary users can open with familiar tools.

Workflow

Spreadsheet → Script → Calendar

A small recurring frustration became a reusable semester setup tool.
