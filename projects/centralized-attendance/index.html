Project 04 • Programme Systems

Centralized Attendance Tracking

A shared source that turns daily attendance entry into programme-level visibility while reducing fragmented recordkeeping.

Challenge

Attendance was previously maintained separately by individual teachers. Practices varied, records were difficult to compare, and the programme manager could not easily identify attendance concerns while there was still time to respond during the semester.

Design response

I designed a shared semester workbook that combines the programme roster, class structure, daily attendance entry, status counts, and calculated attendance marks. I also support colleagues with Microsoft 365 and SharePoint access so the system works in the classrooms and on the devices they actually use.

What the working workbook demonstrates

The completed previous-semester file consolidates approximately 700–800 students across 180 columns. It uses shared status choices and more than 5,000 formulas to count attendance records and apply the same mark calculation across the programme.

Operational value

  • Consistency: all participating instructors use the same status choices and calculation logic.
  • Visibility: the programme manager can review records across teachers, levels, and classes in one place.
  • Timeliness: concerns can be identified during the semester rather than reconstructed afterward.
  • Continuity: the workbook provides one maintained semester record instead of separate personal files.
  • Practical adoption: account, SharePoint, and classroom-device support help colleagues use the system reliably.

Reach and limits

The system is used daily by seven instructors and the programme manager across an English programme serving approximately 700–800 students each semester. Its verified contribution is centralized, consistent, and timely programme information. I do not claim a measured change in attendance or student outcomes without formal comparative data.

Privacy by design

The public portfolio shows only an anonymized reconstruction. The real workbook, student identities, IDs, class assignments, and attendance histories remain private within the institution’s shared environment.

Lesson learned

Centralizing records is only the first step. A system creates value when colleagues can use it consistently and shared information becomes timely enough to support action.
