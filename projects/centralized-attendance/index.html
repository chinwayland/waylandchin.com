Project 04 • Programme Systems

Centralized Attendance Tracking

A shared source that turns daily attendance entry into programme-level visibility.

Challenge

Attendance was previously maintained separately by individual teachers. Records were difficult to compare, practices varied, and the manager could not easily identify patterns during the semester.

Design response

The shared workbook organizes attendance by class and instructor while giving the programme manager a consolidated view. I also supported Microsoft 365, SharePoint, and classroom access so colleagues could use it consistently.

How it works

  1. Maintain a shared semester roster and class structure.
  2. Give instructors access through the programme’s Microsoft environment.
  3. Record attendance during daily teaching.
  4. Review consolidated records for patterns and concerns.
  5. Update the structure as classes or rosters change.

Reach and reflection

The system is used daily by seven instructors and the programme manager across approximately 700–800 students each semester. Its main value is timely visibility rather than simply putting records in one file.

Evidence to addFully anonymized workbook, before-and-after workflow, and manager-view walkthrough. No student identifiers or attendance histories will be published.

Lesson learned

A system creates value when shared information becomes actionable and supports earlier intervention.
