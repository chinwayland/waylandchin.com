Project 02 • Assessment

Speaking Assessment Platform

A focused browser interface for individual speaking assessments.

Challenge

Examiners need to manage prompts, timing, and sequence while concentrating on student performance. Paper materials add handling and can produce different workflows between examiners.

Design response

The platform places prompts and timed stages into one simple interface. It runs in a browser, requires no software installation, and can be updated between semesters.

How it works

  1. Open the assessment in a modern browser.
  2. Begin the required sequence.
  3. Present standardized prompts while the interface supports timing.
  4. Keep attention on the student rather than paper or timekeeping.
  5. Review the workflow after the assessment period.

Reach and reflection

The platform is used by multiple Pre-Intermediate instructors. I use it for approximately 100–125 individual assessments each semester. It supports consistency without replacing examiner judgment.

Evidence to addInterface screenshots, navigation diagram, short screen recording, and a privacy-approved demonstration. Live exam content will not be published.

Lesson learned

For assessment software, reliability, clarity, and ease of use matter more than feature count.
