Project 02 • Assessment

Speaking Assessment Platform

A browser-based examiner interface that combines randomized prompts, timing, and a three-part assessment flow.

Challenge

One-to-one speaking assessments require an examiner to listen carefully while also managing questions, timing, and transitions. Printed question sheets add handling, repeat the same visible prompts, and make the process more dependent on each examiner's personal workflow.

Design response

I built a focused web application for the Pre-Intermediate speaking exam. It displays one large prompt at a time, tracks elapsed time, selects another prompt without immediately repeating the previous one, and moves the examiner through Parts A, B, and C. At the end of Part C, one action resets the application for the next student.

Examiner workflow

01Start a studentThe timer begins and Part A opens automatically.
02Select promptsA large button presents another randomized prompt within the current part.
03Move through partsThe second control advances from A to B to C.
04Reset cleanlyFinish / New Student returns to Part A and restarts the timer.

What the implementation demonstrates

The application is a self-contained HTML, CSS, and JavaScript tool hosted through GitHub Pages. It requires no installation, stores no student information, and can be updated centrally before a new assessment period.

Design decisions

  • One prompt at a time: removes visual clutter and helps the examiner maintain eye contact.
  • Randomized selection: varies questions while preventing an immediate repeat within each part.
  • Elapsed-time display: keeps pacing visible without a separate timer.
  • Two-button navigation: limits the examiner's choices to the next prompt or the next assessment part.
  • Responsive layout: adapts the same interface to landscape and portrait screens.

Reach and limits

I use the platform to administer approximately 100–125 five-minute assessments each semester. Bob also uses it, and Nathan uses it when he conducts a Pre-Intermediate speaking exam. Its present reach is limited to that level; some colleagues continue to use printed questions.

The platform standardizes prompt presentation, timing visibility, and examiner flow. It does not score students or replace professional judgment, and I have not yet collected comparative reliability or time-saving data.

Lesson learned

Assessment software creates the most value when it removes small operational distractions. A clear, reliable interface helps the examiner devote more attention to listening and evaluating.
